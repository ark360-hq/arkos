# Security Policy

## Supported versions

ARK OS is currently at v0.2.1. Security fixes are applied to the latest release only.

| Version | Supported |
|---|---|
| 0.2.x | Yes |

---

## Coordinated disclosure

ARK360 follows coordinated disclosure. If you discover a security vulnerability in ARK OS:

1. **Do not open a public GitHub issue.** Public disclosure before a fix is available puts users at risk.

2. **Contact ARK360 directly.** Send a description of the vulnerability to the ARK360 security contact. Include:
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested mitigations

3. **Allow reasonable time for response.** ARK360 will acknowledge receipt within five business days and aim to provide a resolution timeline within ten business days.

4. **Coordinate public disclosure.** ARK360 will work with you to agree a disclosure date after a fix is available.
